# Makia Android Connector — GPL boundary

The Android connector build is a derivative of **SagerNet/sing-box-for-android** and links the sing-box **libbox** runtime.

- Upstream SFA: https://github.com/SagerNet/sing-box-for-android
- Upstream sing-box: https://github.com/SagerNet/sing-box
- Pinned SFA source commit: `a3668ae6e4bbcb3ceff8461d0cac55d79edf504f` (1.14.1)
- Pinned sing-box core: `v1.14.1`

This Android connector/overlay is distributed under **GPL-3.0-or-later**. It is intentionally isolated under `client/android/` and is not used as a library by the Makia server application.

The public application name is **Makia Connector**. It does not use the SFA name or claim association with SagerNet.
