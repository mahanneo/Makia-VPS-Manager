Makia Android Connector 1.6.3 — install notes

Stable APK:
Makia-Android-Connector-1.6.3.apk

WStunnel 443:
- Full Device Direct Connect is supported on Android ARM64.
- The official Wstunnel 11.0.0 runtime is bundled inside the Makia Connector.
- Users do not need to install Wstunnel or OpenVPN separately.
- Sign in to the Makia Client Portal, choose WStunnel 443, and tap Direct Connect.
- Android asks for VPN permission the first time only.

Requirements:
- Android 7.0 or newer (API 24+).
- ARM64 is required for WStunnel 443 in 1.6.3.
- Allow installation from the browser/files app if Android asks.

If Android says "App not installed" and an older Makia Connector RC is already installed:
- Uninstall only the old Makia Connector app, then install the stable signed APK.
- This removes only local connector app data. It does not rotate, delete, or recreate any VPS user, UUID, WireGuard key, certificate, or server credential.

GitHub Actions UAT builds remain debug-signed and are not the stable distribution artifact.
The stable release APK is produced by the protected Android Signed Release workflow with the persistent release signing identity.
