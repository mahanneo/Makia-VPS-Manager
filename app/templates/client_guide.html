Xray

روش ۱ — QR مستقیم
  1. کلاینت سازگار مثل v2rayNG، Hiddify یا NekoBox را باز کن.
  2. گزینه Scan QR / Add from QR را بزن.
  3. QR «اتصال مستقیم» را اسکن کن.
  4. پروفایل ساخته‌شده را انتخاب و Connect کن.
روش ۲ — Copy Link
  1. لینک مستقیم ارسالی را Copy کن.
  2. در برنامه گزینه Import from Clipboard / Add from Clipboard را انتخاب کن.
  3. پروفایل Import شده را فعال کن.
روش ۳ — Subscription
  1. Subscription URL یا QR اشتراک را از صفحه کاربر بگیر.
  2. در بخش Subscription برنامه، Add subscription را بزن.
  3. URL را Paste یا QR را Scan کن.
  4. Update/Refresh subscription را اجرا کن.
اگر پروفایل REALITY است، SNI / Public Key / Short ID از داخل Share Link منتقل می‌شوند و نباید دستی تغییر داده شوند. برای TLS نیز تاریخ و ساعت دستگاه باید درست باشد.

NATIVE VPN PROFILE

WireGuard

Android / iPhone
  1. برنامه رسمی WireGuard را باز کن.
  2. روی + بزن.
  3. Create from QR code را انتخاب و QR را اسکن کن، یا Import from file را برای فایل .conf بزن.
  4. Tunnel را روشن کن.
Windows / macOS
  1. WireGuard را نصب و باز کن.
  2. Import tunnel(s) from file را انتخاب کن.
  3. فایل .conf را انتخاب کن.
  4. Activate را بزن.
اگر روی یک شبکه خاص وصل نشد، اول Mobile Data و Wi‑Fi را جداگانه تست کن. Endpoint، Port، MTU یا DNS را خودسرانه تغییر نده؛ تنظیمات سازگاری توسط مدیر سرویس تعیین شده‌اند.

OpenVPN

OpenVPN Connect
  1. فایل .ovpn دریافتی را روی دستگاه ذخیره کن.
  2. OpenVPN Connect را باز کن.
  3. Upload File / Import Profile را بزن.
  4. فایل را انتخاب و Add کن.
  5. پروفایل را Connect کن.
فایل OVPN شامل Certificate و تنظیمات اختصاصی همان کاربر است. اگر Endpoint دامنه است، رکورد A باید مستقیم به VPS اشاره کند و برای سرویس‌های Proxy/CDN معمولی مثل Cloudflare در حالت Proxied مناسب نیست. HTTPS پنل با TLS داخلی OpenVPN متفاوت است.

SSH · NPV TUNNEL / NAPSTERNETV

SSH و NPV Tunnel

NPV Tunnel / NapsternetV
  1. لینک npvt-ssh:// را Copy کن یا QR مربوط به NPV را باز کن.
  2. در نسخه سازگار برنامه، Scan QR یا Import from Clipboard را انتخاب کن.
  3. پروفایل ساخته‌شده را ذخیره و Connect کن.
OpenSSH
  1. Server، Port، Username و Password را از فایل credentials بردار.
  2. در Termux/Linux/macOS از ssh USER@SERVER -p PORT استفاده کن.
  3. در Windows می‌توانی Windows Terminal / OpenSSH یا یک کلاینت SSH سازگار استفاده کنی.
OpenSSH رمز عبور را داخل فایل config ذخیره نمی‌کند. Password/PIN را جداگانه نگه دار. اگر NPV Import در نسخه برنامه تو شناخته نشد، از اطلاعات SSH به‌صورت دستی استفاده کن.
TROUBLESHOOTING

اگر وصل نشد چه کار کنم؟

۱. ابتدا ساده‌ترین موارد

اینترنت دستگاه، تاریخ/ساعت، فعال نبودن VPN دیگر و درست بودن QR/Link را بررسی کن.

۲. شبکه دیگری تست کن

Wi‑Fi و Mobile Data را جداگانه امتحان کن. بعضی شبکه‌ها یک پروتکل خاص را محدود می‌کنند.

۳. تنظیمات را دستکاری نکن

UUID، Password، Public Key، SNI، Port و Endpoint را تغییر نده مگر مدیر سرویس گفته باشد.

۴. برای پشتیبانی

نام پروفایل، نوع برنامه، سیستم‌عامل و متن خطا را برای مدیر ارسال کن؛ Credential کامل را در گروه عمومی نفرست.
