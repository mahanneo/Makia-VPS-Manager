MAKIA Desktop for Windows — 0.1.0 RC (test only)

This is a genuine desktop Windows application, NOT a Chrome PWA or an
embedded website. It uses the existing Makia full-device connector. A full
device VPN may require one Windows UAC confirmation and compatible local
runtime/driver. No silent claims of connection without changed exit IP.

INSTALL (Windows x64):
1. Extract the complete ZIP into a local folder. Do not run a ZIP entry.
2. Close existing Makia Desktop/Connector and disconnect any active tunnel.
3. Double-click Install-Makia.cmd. Do NOT install on an active production
   user's machine until its session and installer rollback are tested.
4. Start "Makia Desktop" via the new Desktop/Start Menu shortcut.
5. Leave the controller as https://p.mahinet.shop (or your own HTTPS domain),
   enter the Client subscription account ONCE, and optionally check Remember
   this Windows login for up to 30 days.
6. Pick an available service and press اتصال VPN. Accept Windows UAC if
   requested. A changed HTTPS public exit IP is required for a green result.
7. Press قطع اتصال explicitly to return to direct browsing. Exit account
   removes the saved bearer; it does not silently remove an active tunnel.

No need to visit /client in the browser after installing, as long as the
matching new desktop API has been safely deployed to the Makia server.

Package:
- MakiaDesktop.exe: non-elevated native Tk desktop user interface
- MakiaClientConnector.exe: existing elevated one-time ticket redeemer / TUN
- sing-box.exe, wstunnel.exe: pinned, checksum-verified Windows runtimes
- Install-Makia.cmd, Uninstall-Makia.cmd, install.ps1, uninstall.ps1
- BUILD-INFO.txt, SHA256SUMS.txt (generated by GitHub Actions)

Supported runtime paths (depending on actual account and host):
- Xray VLESS / VMess / Trojan / Hysteria2 and Outline/Shadowsocks / SSH:
  sing-box TUN via existing converter, subject to real Windows UAT
- WireGuard: requires official WireGuard for Windows installed
- OpenVPN, OpenVPN WStunnel: require compatible OpenVPN binary installed
- PPTP and unsupported engines: NOT claimed as one-click full-device support

Security:
- Password is never saved in a file.
- Remember-device account bearer token is DPAPI CurrentUser encrypted and
  server-side only its hash is stored. It expires absolutely in <=30 days,
  and may be revoked via account logout/device revoke/password rotation.
- No raw VPN secret in the desktop GUI, logs or custom protocol URI.
- A one-time connector ticket lasts 60 seconds and is device/account-bound.
- If public HTTPS egress cannot be verified, display UNVERIFIED instead
  of fake Connected. A VPN driver may still hold routes; disconnect explicitly.
- Unsigned trial EXEs may trigger Windows SmartScreen; do NOT bypass
  organizational security policies. Production distribution requires signing.

Logs: %LOCALAPPDATA%\Makia\Connector\connector.log
Saved device state: %LOCALAPPDATA%\Makia\Desktop\device.json (DPAPI encrypted)
Uninstall via Uninstall-Makia.cmd. This removes local saved login and shortcuts;
revoke the device remotely too if you want to invalidate its server token.

RELEASE GATE: Source CI and GitHub package build are necessary but NOT
sufficient. Real Windows native test + actual server API deployment + IP/DNS
egress, Windows restart, token/session expiry and rollback must PASS.
