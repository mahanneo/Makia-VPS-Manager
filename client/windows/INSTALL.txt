Makia Windows Full Device Connector installer 1.6.4.1

Purpose:
This package is only for full-device VPN on Windows.

Browser-only users:
Do NOT install this package.
Use Makia Browser VPN from Chrome/Edge instead. Browser VPN connects directly to the Makia Browser Gateway and needs no EXE, Registry Native Messaging host or local sing-box.

Install:
1. Extract the ZIP once.
2. Extract to a folder (spaces in the path are supported). Double-click Install-Makia.cmd. Do not run files from inside ZIP.
   Run as the Windows user who will use Makia; the makia:// handler is registered per user.
3. Return to the authenticated Makia Client Portal.
4. Use Direct Connect on a supported profile.
5. Windows may show UAC when starting a full-device tunnel.

Included:
- MakiaClientConnector.exe
- sing-box.exe
- wstunnel.exe
- install.ps1 / uninstall.ps1
- Install-Makia.cmd / Uninstall-Makia.cmd

Logs:
%LOCALAPPDATA%\Makia\Connector\connector.log

Uninstall:
Double-click Uninstall-Makia.cmd.

Security:
Direct Connect uses short-lived, one-time, device-bound tickets. Complete VPN credentials are not embedded in makia:// URLs.
